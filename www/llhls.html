srs_simple — LL-HLS 플레이어 (low-latency)

먼저 publish를 시작하세요. LL-HLS는 세그먼트를 키프레임에서 자르므로 GOP ≤ 2초가 필요하다 (-c copy는 원본 GOP를 그대로 쓰므로 재인코딩 권장):
ffmpeg -re -stream_loop -1 -i test.mp4 -c:v libx264 -g 60 -keyint_min 60 -bf 0 -c:a aac -f flv rtmp://localhost/live/test
m3u8는 내장 HTTP 서버(:8081)가 직접 서빙한다 — 블로킹 리로드(_HLS_msn)와 프리로드 힌트 홀드는 정적 파일 서버(nginx)가 못 하는 일이라 오리진이 처리한다. 같은 publish를 기존 HLS 페이지(10초 세그먼트, ~30초 지연)와 나란히 재생하면 지연 차이를 볼 수 있다. 재생은 hls.js(lowLatencyMode)로 한다 — Safari도 Hls.isSupported()가 참이라 이 경로를 탄다 (네이티브 LL-HLS는 CDN 로드 실패 시 폴백이며, 현재 서버에서는 거부된다 — CLAUDE.md §8 S17).
라이브 전용: 뒤로 감기나 일시정지 후 재개는 라이브 엣지로 스냅한다.
